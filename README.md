## 🚀 Getting Started

Follow these steps to run the labs on your own machine.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/1Jawahir-Ali/ML-Lab-2024-SE-34.git
cd ML-Lab-2024-SE-34
```

### 2️⃣ Create a virtual environment *(recommended)*

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3️⃣ Install the dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 4️⃣ Launch Jupyter Notebook

```bash
jupyter notebook
```

Then open any lab folder (e.g. `Lab01`) and run the notebook.

> ☁️ **Prefer the cloud?** Upload any notebook to [Google Colab](https://colab.research.google.com/) and run it without installing anything.
