# 🐍 Python Lab 01: Warm-up, Data Structures & Functions

A hands-on lab covering Python fundamentals, built and run in Jupyter Notebook.

## 📌 Topics Covered

| Category | Tasks |
|----------|-------|
| **Basics** | Arithmetic, string splitting, `.format()` formatting |
| **Data Structures** | Nested list/dict indexing, tuple vs. list |
| **String Handling** | Email domain extraction, case-insensitive word search & count |
| **Functions** | Speeding ticket, palindrome checker, finding the topper |

## 🛠️ Tools
- Python 3
- Jupyter Notebook

## 🎯 Learning Outcomes
Strengthened skills in string methods, slicing, indexing, lists, dictionaries, functions, and conditional statements.
